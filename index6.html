Loan Default Prediction

Predicted whether a customer will be able to repay the loan or not. We also performed Data Preprocessing steps, Exploratory Data Analysis. SVD in Image Compression

Understood and implemented Image Compression using Technique in Linear Algebra called as Singular Value Decomposition. Understood transformation of Images to Matrices. Memory can be saved drastically by storing just the most important information from the matrices about the image. A recognizable image similar to original image is created which is thus requiring extremely low storage space.

November 18, 2023

A Comparative Study on Stock Market

Goal: Understanding storage of unstructured data MongoDB and establishing a seamless connection between MongoDB, Python and PowerBI. Conducted extensive stock market analysis across five domains over a five-year period as part of a team effort. Selected and analysed 2-3 companies in each domain, performing comparative analysis before COVID-19 pandemic and after COVID-19 pandemic. Utilized Python for data collection, stored data in MongoDB Atlas as unstructured time series data and created insightful dashboards in Power BI. Presented findings for informed decision-making.

March 5, 2024

Protecting American Environments

Collected and Manually Annotated Gunshot Audio from Google AudioSet Dataset and UrbanSound 8K. Transformed raw Audio Data to Audio Signals; extracted the MFCC Coefficients. Trained diverse models such as CNN, RNN, LSTM and Hybrid Model with varied architectures on 2 second segmented data. Model with bidirectional and dropout layer performed best with Test Accuracy of 88.94% and Recall of 92.90%. Implemented the Best Model on Gradio for Real Time Gunshot Detection.
